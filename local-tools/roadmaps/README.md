# Local tools: roadmaps

These learning roadmaps and trackers are kept in the repository for local use
only. They were moved out of `public/` so they are no longer served by the
portfolio or linked from any route.

Open them directly from disk, for example:

- `be-roadmap/index.html` (uses the sibling `css/` and `js/` files)
- `cpp-mastery-tracker.html`
- `DEPRECATED-se-roadmap.html`
- `DSA-Learning-Roadmap.md`
- `roadmap.md`

Do not place these back under `public/` unless you intend them to be public.
